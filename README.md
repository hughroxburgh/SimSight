# SimSight: Measuring Cosmic Properties in Many Sightlines 

This pipeline loads data from cosmological simulations and shoots sightlines through the comoving simulation box. Users can choose the number, direction, origin, and some computed value to accrue for each sightline.

Current simulations supported: TNG, SIMBA.

To install this package, just run `pip install git+https://github.com/rhoxu/SimSight.git`.
